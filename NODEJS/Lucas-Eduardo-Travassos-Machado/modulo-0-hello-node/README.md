# hello-node

Esse projeto foi feito como parte da atividade prática do Módulo 0 da disciplina de Desenvolvimento Backend. A ideia principal é validar se o ambiente de desenvolvimento que configurei (Node.js usando nvm, TypeScript e Docker) está funcionando corretamente. Quando o projeto roda, ele mostra a versão do Node.js que está sendo usada e também o horário em que essa validação foi feita.

Sobre as decisões técnicas, deixei o TypeScript configurado em modo estrito (strict true no tsconfig.json), assim ele fica bem rigoroso na checagem dos tipos antes de rodar o código. Para a dependência externa eu escolhi a biblioteca dayjs, que uso para formatar a data e hora da validação de um jeito mais legível. Escolhi ela porque é bem leve e simples de usar, não precisava de nada mais robusto pra esse projeto pequeno. O package.json também está configurado como module (ECMAScript Module) porque a sintaxe de import que uso no código pede isso, no começo eu tinha deixado como commonjs e deu erro de compilação, então entendi na prática a diferença entre os dois formatos. Também configurei ESLint e Prettier como dependências do próprio projeto, e um arquivo editorconfig pra manter o padrão de indentação e charset.

Pra rodar o projeto na sua máquina, primeiro precisa ter o Node.js instalado (o ideal é usar a versão LTS mais recente via nvm). Depois de clonar, roda npm install pra instalar as dependências e npx tsx src/index.ts pra executar. Também dá pra rodar dentro de um container Docker, construindo a imagem com docker build -t hello-node . e rodando com docker run --rm hello-node. O resultado esperado é o mesmo nos dois casos, só muda o ambiente onde está rodando.
