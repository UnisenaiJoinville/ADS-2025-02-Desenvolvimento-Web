# Etapas que precisam ser executadas pelo aluno

```bash
git init
git add .
git commit -m "chore: inicia projeto TypeScript em modo estrito"

# Faça a alteração referente à funcionalidade/dependência e então:
git add .
git commit -m "feat: adiciona funcionalidade principal"

# Finalize qualidade e documentação:
git add .
git commit -m "docs: finaliza README e configuracoes"

git branch -M main
git remote add origin git@github.com:ORGANIZACAO/NOME-DO-REPOSITORIO.git
git push -u origin main
```

Substitua ORGANIZACAO e NOME-DO-REPOSITORIO pelos dados reais. O requisito de três commits precisa aparecer no histórico real do GitHub.
