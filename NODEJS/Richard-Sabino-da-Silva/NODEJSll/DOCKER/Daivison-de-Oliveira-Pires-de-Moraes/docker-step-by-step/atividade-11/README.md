# Atividade 11: Inspecionando um container

## Objetivo
Ver os metadados completos de um container em execução.

## Comandos executados
```bash
docker inspect <container_id>
```

## O que foi observado / evidenciado
Retorna um JSON completo: IP interno, volumes montados, variáveis de ambiente, configuração de rede, comando executado, status, portas expostas, políticas de restart etc.
