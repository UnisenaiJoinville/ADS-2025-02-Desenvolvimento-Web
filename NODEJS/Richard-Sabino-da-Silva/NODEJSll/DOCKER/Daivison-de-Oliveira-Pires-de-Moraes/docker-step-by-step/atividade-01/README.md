# Atividade 01: Instalação do Docker

## Objetivo
Instalar o Docker Engine/Desktop e confirmar que o CLI está funcionando.

## Comandos executados
```bash
docker --version
```

## O que foi observado / evidenciado
Saída esperada: `Docker version 27.x.x, build xxxxxxx`. Confirma que o binário do Docker CLI está instalado e acessível no PATH.
