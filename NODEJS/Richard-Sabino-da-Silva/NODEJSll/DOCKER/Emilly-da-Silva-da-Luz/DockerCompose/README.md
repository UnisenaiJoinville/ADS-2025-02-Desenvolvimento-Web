# DockerCompose — versão alternativa

Esta pasta reúne as 25 atividades propostas no material de Docker e Docker Compose, organizadas em `1 - Atividade`, `2 - Atividade` e assim por diante.

A solução desta versão foi escrita de maneira diferente da primeira: exemplos, textos, nomes de banco, domínio das aplicações e organização das respostas foram alterados, mantendo os requisitos do enunciado.

## Projetos usados
- Cenário 1: Vue + Node/Express + MySQL + Redis + RabbitMQ + Worker. Exemplo: catálogo de livros.
- Cenário 2: React + Node/Express + PostgreSQL + Redis + RabbitMQ + Nginx. Exemplo: painel de tarefas.
- Cenário 3: Vue + Node/Express + MySQL + Redis + RabbitMQ + Worker + Nginx. Exemplo: central de chamados.

## Observação sobre evidências
Atividades que exigem `docker compose ps`, logs ou prints possuem `EVIDENCIAS.md`. Esses arquivos indicam exatamente o que deve ser coletado após a execução real do Docker.
