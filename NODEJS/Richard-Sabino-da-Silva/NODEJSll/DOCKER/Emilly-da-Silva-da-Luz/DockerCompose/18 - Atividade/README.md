# 18 - Atividade — P1: `.env.example` do Cenário 1

O arquivo `projeto/.env.example` foi criado de acordo com as variáveis usadas pelo Compose desta versão. Ele utiliza somente valores didáticos e não contém credenciais reais.

As variáveis incluem configuração do MySQL, RabbitMQ, hosts internos e porta da aplicação. O `.env` verdadeiro está previsto no `.gitignore`.
