--- Ativ 22: Limitando recursos ---
$ docker run -m 512m --cpus=1.0 ubuntu
memoria limite (bytes):
536870912

EXPLICACAO: -m 512m limita a memoria RAM que o container pode usar e
--cpus=1.0 limita a um nucleo. Serve para um container nao consumir a
maquina inteira e derrubar os outros servicos. Em producao isso evita
que um vazamento de memoria em um servico afete o resto.

EXPLICACAO das metricas:
  CPU %    - quanto do processador o container esta usando
  MEM USAGE - memoria usada / limite definido (se nao tem limite, mostra o total da maquina)
  NET I/O  - trafego de rede que entrou e saiu
  BLOCK I/O - leitura e escrita em disco
Serve para achar qual container esta pesando antes de culpar a maquina.
