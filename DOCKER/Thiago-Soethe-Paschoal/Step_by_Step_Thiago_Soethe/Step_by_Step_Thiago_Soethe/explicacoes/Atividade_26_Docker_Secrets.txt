ATIVIDADE 26 — USANDO DOCKER SECRETS

Comandos utilizados:
docker swarm init
echo "minha-senha" | docker secret create minha-senha -
docker service create --name servico-secret --secret minha-senha nginx
docker service ls
docker secret ls
docker service ps servico-secret

Explicação:
Primeiro foi inicializado o Docker Swarm para permitir a utilização
do recurso Docker Secrets.

Depois foi criado um secret chamado minha-senha.

Em seguida, foi criado um serviço Nginx chamado servico-secret,
associando o secret ao serviço.

Os comandos docker service ls, docker secret ls e docker service ps
foram utilizados para verificar o serviço e o secret criados.

Docker Secrets permite armazenar informações sensíveis separadamente
da configuração normal dos containers e disponibilizá-las apenas aos
serviços autorizados.
