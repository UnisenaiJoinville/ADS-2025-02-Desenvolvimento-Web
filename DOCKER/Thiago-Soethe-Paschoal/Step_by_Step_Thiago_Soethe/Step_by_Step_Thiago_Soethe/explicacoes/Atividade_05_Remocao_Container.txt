ATIVIDADE 5 — REMOVENDO UM CONTAINER

Comandos utilizados:
docker ps -a
docker rm 9d0680a18a13
docker ps -a
docker images

Explicação:
Inicialmente foi utilizado o comando docker ps -a para visualizar os
containers existentes.

O container Ubuntu utilizado na atividade anterior foi removido com o
comando docker rm.

Ao executar docker ps -a novamente, o container Ubuntu não apareceu mais
na listagem, confirmando sua remoção.

Depois foi utilizado docker images e foi possível verificar que a imagem
Ubuntu continuava armazenada no Docker.

Isso demonstra que um container e uma imagem são recursos diferentes.
Remover um container não remove automaticamente a imagem utilizada para
criá-lo.
