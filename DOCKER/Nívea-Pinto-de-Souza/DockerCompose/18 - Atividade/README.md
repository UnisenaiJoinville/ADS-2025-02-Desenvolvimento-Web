# 18 - Atividade — P1 — criar .env.example do cenário 1


## Entrega
O arquivo `.env.example` está em `projeto/.env.example` e contém somente valores de laboratório, sem credenciais reais.

Variáveis: `MYSQL_DATABASE`, `MYSQL_USER`, `MYSQL_PASSWORD`, `MYSQL_ROOT_PASSWORD`, `RABBITMQ_USER`, `RABBITMQ_PASSWORD`, `DB_HOST`, `REDIS_HOST` e `RABBITMQ_HOST`.
