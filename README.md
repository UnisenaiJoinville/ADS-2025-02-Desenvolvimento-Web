# ADS-2025-02 · Desenvolvimento Web

Repositório da turma de Desenvolvimento Web — 2º semestre de 2025 (ADS, turma iniciada em 2025).

## Estrutura

- [`BANCO-DE-DADOS/`](BANCO-DE-DADOS/) — projetos de Banco de Dados
- [`NODEJS/`](NODEJS/) — projetos de Node.js
- [`DOCKER/`](DOCKER/) — projetos de Docker

## Como enviar seu projeto

1. Crie uma subpasta dentro da pasta da matéria correspondente, com seu nome (ex.: `NODEJS/joao-silva/`).
2. Coloque os arquivos do seu projeto dentro dessa subpasta.
3. Faça commit e envie para o repositório (via Pull Request ou push, conforme orientado em aula).
